# 📈 Projects

## 1. Southern Water Corp Financial Analysis

### Project Overview

This project analyzes the financial and operational performance of
Southern Water Corp.

The objective was to investigate revenue, operating expenses, and
profitability across the company's plants and identify opportunities
to improve financial performance.

### Analysis

The project included analysis of:

- Revenue
- Operational expenses
- Chemical costs
- Plant performance
- EBIT
- EBIT margin

### Key Findings

The analysis identified increasing operating costs as an important
factor affecting profitability.

The Surjek plant generated strong revenue but experienced
disproportionately high chemical costs.

### Recommendation

Focus on controlling chemical expenses at the Surjek plant to improve
overall profitability.

The analysis indicated the potential to achieve approximately:

- **EBIT: $40M**
- **EBIT Margin: 20%**
